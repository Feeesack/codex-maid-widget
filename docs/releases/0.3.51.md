# Codex Maid Widget v0.3.51

[简体中文](#简体中文) · [English](#english)

## 简体中文

本版本汇总 v0.3.48 之后的中英双语界面、英文文案复核，以及 PR #1 的 macOS 窗口修复。

### 更新内容

1. **中英双语界面**：在设置顶部选择简体中文或 English，立即应用到七个气泡页面、设置、提示、托盘/菜单栏和图片导入对话框，并在重启后保留。英文调整字号、间距、换行和数字/日期显示；中文仍为默认。
2. **英文文案复核**：复核默认台词、界面术语、账号历史窗口说明和 Mac 插件连接结果。自定义台词、重命名形象、账号别名、项目/对话名称和文件路径保留原文，切换语言不覆盖编辑草稿。
3. **macOS 窗口识别与跟随**：改进 Codex 主窗口识别、焦点变化后的层级恢复和平滑跟随；移动窗口时不反复重置人物尺寸或刷新界面。
4. **有界显隐恢复**：沿用稳定期、持续隐藏判断和最多三次重试。恢复前采样、恢复后才返回的隐藏快照不会连续触发重映射；手动隐藏或切换到其他前台应用会取消待执行的恢复。
5. **修复聚焦后的气泡裁剪**：macOS 使用 `overflow: clip`，避免内部滚动状态在角色获得焦点后裁掉气泡。Windows 既有窗口和互动行为保留。

### 升级与验证范围

升级保留既有设置、导入形象、有效选择和原始素材。真实额度需要本机安装并登录官方 Codex 桌面应用。可选本地插件通过明确的连接入口启用，不自动注册或上架插件市场。

感谢 [PR #1](https://github.com/Feeesack/codex-maid-widget/pull/1) 的 macOS 修复贡献。「DSH 小黄鸭」沿用 [MeteorNOX/DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget) 的 `Ya1.mp3` / `Ya2.mp3` 原音频，来源提交和独立许可范围见[音频资料](https://github.com/Feeesack/codex-maid-widget/blob/v0.3.51/docs/interaction-audio.md)与 [NOTICE](https://github.com/Feeesack/codex-maid-widget/blob/v0.3.51/NOTICE)。这些音频不属于本项目 MIT 或 CC BY 4.0 授权范围。

Windows 0.3.51 已核对本机主程序、后台助手、非演示额度、本地控制和 MCP；安装包通过中文/空格路径、非系统盘、自定义数据目录、运行中升级、卸载及数据保留检查。双端源码与集成模块的 1295 项隔离回归通过。macOS 通用安装包由原生 runner 构建，同一个包在 Apple Silicon 与 Intel runner 上通过安装、启动、本地控制、MCP、原生窗口与 launchd 助手检查。Mac CI 使用隔离演示环境，真实账号与人工桌面体验另行验收。

Spaces、全屏、多屏、Retina、声音、登录会话、真实五小时提醒及 Windows 注销重登仍需人工体验。Windows 安装包未签名；Mac 应用采用 ad-hoc 签名，安装包未签名且未经过 Apple 公证。

## English

This release combines the changes since v0.3.48: a bilingual interface, reviewed English copy and the macOS window fixes from PR #1.

### Changes

1. **Chinese and English interface**: choose Simplified Chinese or English at the top of Settings. The choice immediately updates all seven bubble pages, settings, notices, native menus and image-import dialogs, and persists across restarts. English has adjusted spacing, type sizes, wrapping and number/date formatting; Chinese remains the default.
2. **Reviewed English copy**: refine built-in phrases, interface terms, historical-account estimates and Mac connector results. Custom phrases, renamed characters, aliases, project/conversation names and file paths remain as written. Changing language preserves edits in progress.
3. **macOS window identification and following**: improve Codex main-window detection, stacking after focus changes and smooth following. Moving the host window does not repeatedly resize the character or republish the interface.
4. **Bounded visibility recovery**: retain the settle period, sustained-hidden check and three-attempt limit. Delayed snapshots captured before a remap no longer restart recovery after the widget is visible. A manual hide or another foreground app cancels pending recovery.
5. **Focus-clipping fix**: use `overflow: clip` on macOS so internal scroll state cannot crop the bubble after the character receives focus. Existing Windows window and interaction behavior is retained.

### Upgrade and verification

Upgrades preserve settings, imported characters, valid selections and original assets. Live quota requires the official Codex desktop app to be installed and signed in. The optional local plugin uses an explicit connection step; it is not automatically registered or published to a marketplace.
