# Codex Maid Widget 0.3.49 — 本地双语更新 / Local bilingual update

## 简体中文

设置顶部新增 **界面语言**，可以选择 **简体中文 / English**。切换立即作用于设置页、七个气泡页面、提示、原生托盘/菜单栏菜单和图片导入对话框，并持久保存。

中文默认与现有文案保持一致。英文独立调整字号、间距和自然换行，覆盖额度、上下文占用、Git 未提交文件、压缩次数、多账号记录和音色说明。数字、日期及紧凑 token 单位按当前语言显示。

只有整套未改动的默认台词和未重命名的内置形象使用英文译文。自定义台词、形象名称、账号别名、项目及对话名称、文件路径均保持原文；切换语言不会覆盖正在编辑的草稿。

两端源码版本均为 0.3.49。Windows 本地构建与实际运行验证、双端回归和真实渲染器排版检查分别留档；Mac 原生构建、系统交互和人工实机体验不由 Windows 上的界面检查代替。本次未生成或发布安装包，最近公开安装包仍为 0.3.48。

## English

Choose **简体中文 / English** using **Interface language** at the top of Settings. Changes apply immediately to settings, all seven bubble pages, notices, native tray/menu-bar menus and image-import dialogs, and are remembered on restart.

Chinese remains the default. English has its own spacing, type sizes and wrapping for longer labels. Usage limits, context usage, uncommitted Git files, compactions, local account records and sound descriptions are translated; number and time formatting follows the selected language.

Only untouched built-in phrase sets and default character names are translated. Custom phrases, renamed characters, account aliases, project/chat names and file paths remain as written. In-progress edits survive language changes.

Windows and Mac source versions are aligned at 0.3.49. Windows runtime checks, cross-platform source regression tests and isolated renderer layout checks are recorded separately. Mac native build and hands-on checks remain distinct from renderer checks on Windows. No installer is generated or published for this local update; the latest published installers remain at 0.3.48.
