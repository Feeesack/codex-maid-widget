# Codex Maid Widget v0.3.48

[简体中文](#简体中文) · [English](#english)

## 简体中文

本次版本汇总了 v0.3.21 以来的改进，重点是互动手感、多账号重置提醒、对话状态与界面设置。Windows 与 macOS 使用同一版本号。

### 更新内容

1. **弹跳动画与音效**：将互动拆为按下、抬起两段，各有独立动作与音效。连点从当前姿态继续，减少重启动画的顿挫；拖动保持压下姿态，松手后回弹。提供「气泡轻弹」「轻柔弹簧」「经典啾啾」「木质轻敲」「DSH 小黄鸭」五套音色，设置内可试听。整体互动音量提高，默认气泡按下声单独加强。音效来源与许可范围见[音频资料](../interaction-audio.md)。
2. **多账号额度记录与重置闹钟**：记录本机已观察到的账号，为每个账号分别显示五小时额度窗口、倒计时与重置时刻。到达记录的重置时间，人物与气泡在一秒内连续弹跳四次，并显示挂件文字提醒、播放一次短音。提醒和声音均可关闭。历史账号到期会标注“预计已重置，待登录确认”，不会被当作实时额度；不提供账号切换。
3. **更新小龙娘形象**：加入「小龙娘-托腮」「小龙娘-端庄」，采用无嘴、圆腮帮、大眼睛与略微低垂的眉毛，参考 DSH 大肥鱼的可爱表情风格，同时保留 GPT 小龙娘的设定与特征。全新设置默认托腮形象，原有形象、有效选择与自定义名称继续保留。
4. **对话上下文、压缩次数与 Git 状态**：自动识别 Codex 当前对话，也可从最近最多 30 条符合条件的本地对话中手动选择。展示上下文占用百分比、本地已确认压缩次数，以及对话所在工作区未提交的 Git 文件数（含未跟踪文件）。压缩次数为自动与手动合计，历史不完整时标注；Git 数字不是尚未推送的提交数。翻到该页、点击气泡或切换选择时读取，不新增对话后台轮询。
5. **左右镜像动画**：接入开源 Motion 动画引擎，人物左右切换更平滑，并保持气泡文字可读。
6. **修复工具栏收起与点击问题**：普通鼠标点击留下的按钮焦点不再让工具栏常驻；扩大按钮附近的交互余量并加入短暂收起宽限，移动到按钮时更容易点击，键盘操作继续保留。
7. **独立调节探头藏入宽度**：开启“底角吸附时只露头部”后，可分别调节底边与侧边藏入宽度（0%–200%）。底边默认 50%、侧边默认 100%，拖动实时预览、松开保存；关闭探头保留数值。大小和不透明度滑块也支持实时预览。
8. **气泡页面顺序与显示设置**：新增页面编辑模块，支持 SortableJS 卡片拖拽排序、键盘排序、逐页显隐和启动默认页，至少保留一页可见。
9. **上一页／下一页按钮**：用左右箭头替换原有三点按钮，按自定义可见顺序双向循环翻页。
10. **统一界面图标**：工具栏、翻页及页面编辑控件使用开源 Hugeicons 免费图标，风格统一；图标与动画资源随包提供，不依赖运行时 CDN。
11. **修复不同电脑上的 Codex 路径识别**：改进非默认安装盘、不同用户、启动环境和最小 PATH 下的 Codex 安装及 CLI 发现，避免因路径差异读不到额度。同步改进相关助手与本地插件路径传递。

### 使用与升级

- 使用真实额度前，请先安装并登录官方 Codex 桌面应用。Token 统计汇总本机可用记录，不代表其他设备用量或金额账单。
- 升级保留既有设置、导入形象及有效选择。账号记录是本机已观察窗口的历史记录，需要逐个登录观察；提醒使用挂件内气泡文字。
- 账号昵称和工作空间查询可在本机主进程内使用已有登录凭据向固定官方资料接口发起只读请求；不刷新登录，凭据不进入账号记录、日志、本地控制或 MCP 输出。
- 原创代码、原创素材与第三方素材分别遵循各自许可；「DSH 小黄鸭」不属于本项目 MIT 或 CC BY 4.0 授权范围。详情见 [NOTICE](../../NOTICE)、[图片许可](../../ARTWORK_LICENSE.md)与[音频资料](../interaction-audio.md)。

当前是待确认的 v0.3.48 发布候选，尚未代表 GitHub 正式发布。Windows 已有本机主程序、后台助手、非演示额度、本地控制和 MCP 运行证据，双端源码回归已覆盖交互、数据读取、设置与路径兼容。Mac 新功能已做 Windows 上的源码／渲染检查；本版本 Mac 原生 CI 构建与运行结果待补充。

## English

This release brings together the changes since v0.3.21, focusing on interactions, multi-account reset reminders, conversation status and interface settings. Windows and macOS use the same version.

### Changes

1. **Press/release animation and audio**: interactions now have separate press and release movements with matching sound pairs. Rapid clicks continue from the displayed pose; dragging holds the compressed pose until release. Settings offer Bubble Pop, Soft Spring, Classic Chirp, Wood Tap and DSH Duck, with previews. Playback gain is increased, with an extra boost for the default bubble press. See [audio sources and license scope](../interaction-audio.md).
2. **Multiple account records and reset reminders**: accounts observed on this device each have a recorded five-hour window, reset time and countdown. When a recorded deadline arrives, the character and bubble bounce four times within one second, show widget text and play one short sound. Reminders and sound can be disabled. Expired historical windows are marked as estimated resets requiring login to confirm; this does not switch accounts or connect to every account simultaneously.
3. **New dragon-girl artwork**: 小龙娘-托腮 and 小龙娘-端庄 have mouthless expressions, round cheeks, large eyes and slightly lowered brows, taking inspiration from the DSH whale's expression style while retaining the GPT dragon-girl design. Fresh settings use the cheek pose; existing characters, valid selections and custom names are retained.
4. **Conversation context, compaction and Git status**: automatically detect the current Codex conversation, or manually choose from up to 30 recent eligible local conversations. The page shows context usage, locally confirmed compactions and uncommitted files in the conversation's worktree, including untracked files. Compactions combine automatic and manual operations; incomplete history is marked. The Git figure is not a count of commits waiting to be pushed. Data reads occur when opening the page, clicking its bubble or changing selection, without extra background conversation polling.
5. **Animated mirroring**: the open-source Motion engine provides a smoother transition between left and right layouts while keeping bubble text readable.
6. **Toolbar fixes**: mouse-click focus no longer leaves the toolbar stuck open. A larger interaction margin and a short dismissal grace period make it easier to reach the buttons, while retaining keyboard access.
7. **Independent corner-hiding controls**: with head peeking enabled, adjust bottom and side hiding separately from 0% to 200%, with defaults of 50% and 100%. Changes preview while dragging and save on release; disabling peeking retains the values. Size and opacity also support live preview.
8. **Bubble-page order and visibility**: arrange cards with SortableJS or the keyboard, show or hide pages and choose the startup default. At least one page stays visible.
9. **Previous/next page buttons**: clear left/right arrows replace the ellipsis button and wrap through the configured visible order in both directions.
10. **Consistent icons**: toolbar, pager and page-editor controls use the free Hugeicons set. Icons and animation libraries are bundled locally, with no runtime CDN dependency.
11. **Codex discovery across computers**: improve installation and CLI discovery across Windows installation volumes, user environments, startup contexts and minimal PATH configurations, fixing quota failures caused by path differences. Related helper and local-plugin path handoff is also improved.

### Usage and upgrade

- Install and sign in to the official Codex desktop app for real quota. Token totals combine available local records; they are not a bill or a total across devices.
- Existing settings, imported characters and valid selections are retained. Account cards are historical windows observed locally and require signing in to each account to populate. Reminders appear within the widget.
- For nicknames and workspace names, the local main process can use existing sign-in credentials for read-only requests to fixed official profile endpoints. It does not refresh sign-in or include credentials in account records, logs, control responses or MCP output.
- Original code, artwork and third-party assets have separate license scopes. DSH Duck audio is outside this project's MIT and CC BY 4.0 grants. See [NOTICE](../../NOTICE), [artwork scope](../../ARTWORK_LICENSE.md) and [audio provenance](../interaction-audio.md).

### Release candidate and verification

This is a v0.3.48 candidate awaiting confirmation, not a statement that GitHub publication is complete. Windows has local runtime evidence for the main app and helper versions, non-demo quota, local controls and MCP. Regression checks cover both source trees, including interactions, data reading, settings and path compatibility. New Mac features have source/renderer checks from Windows; native Mac CI build and runtime results for this version are pending.

CI results and hands-on acceptance are separate. Mac Spaces, full screen, multiple displays, Retina, audio and login sessions still need hands-on testing. Subjective sound and animation feel, real five-hour reminders and Windows sign-out/sign-in also need acceptance. Installers do not yet have developer distribution certificates; the Mac app is ad-hoc signed and not Apple-notarized.
