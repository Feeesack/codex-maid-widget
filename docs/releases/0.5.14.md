# Codex Maid Widget v0.5.14

[简体中文](#简体中文) · [English](#english)

## 简体中文

本版本汇总上次公开版本 v0.3.51 之后的更新。Windows x64 与 macOS 13+ 通用安装包均已完成构建、校验和与真实安装启动验证。

### 更新内容

1. **桌宠图文聊天与持久记忆**：通过已登录的 Codex 账号发送文字和图片，接收流式回答，支持中断与模型选择。专用项目保存人设、偏好和事实档案；检查点保留可追溯的原文、原图、摘要与修订，离线检索可回查历史，换聊在资料核验后切换。
2. **聊天管理与原生用量**：当前聊天、用量记录、归档历史、记忆档案、换聊与维护、做梦维护、项目与模型共七个入口。新增聊天专属原生 token 账本、容量与正文增长显示、维护阶段和预算；未知计量保持未知。归档标题、标签、收藏及隐藏状态使用独立元数据，原始 JSONL 与图片保留。
3. **更清楚的设置与输入**：设置分为常规、外观、气泡与显示、聊天、交互与声音五类。气泡正文为 14px，展开书写卡片为 16px；同一输入框保留草稿、选区、输入法状态及发送期间的新输入。Enter 换行、Ctrl/Cmd+Enter 发送、Escape 收起，中英和减少动画设置均适用。
4. **聊天恢复与模型发现**：核对按钮显示进度和具体结果；兼容的容量证明经过完整性、原线程终态和当前能力核验后，可在程序或 CLI 升级后恢复。writer 占用、认证失效、容量不足与未知执行分别处理，保留原线程和输入，不自动重发未知请求或提前换聊。模型刷新读取经过核验的原生目录，支持目录实际提供的 Terra 等模型。
5. **保留既有桌面功能**：保留额度、账号历史窗口、重置预测、角色与原图、音效、页面设置及本地控制。Windows 跟随使用由 Codex 主窗口拥有的独立顶层窗口；macOS 继续使用独立跟随窗口。升级保留用户已有设置和导入形象。
6. **重置预测与公告提醒接入**：重置预测页接入 `codex-reset.com` 的受限公开公告与观察数据，显示来源引用、公告/观察截止时间、真实目标倒计时、24/48 小时概率、置信度、上次确认时间和数据新鲜度。每个本机观察账号保留五小时窗口进度；到期用挂件文字、一秒四次弹跳和一次短音提醒，提醒去重且可关闭，历史估算标记为待登录确认。公告信号、观察信号、Tibo 自述与真实额度确认保持分层，不能互相冒充；网络失败、来源过期或变更时保留有界缓存并标记 stale/offline，不阻塞启动。

### 使用与升级

真实额度需要安装并登录官方 Codex 桌面应用。聊天需启用可选聊天页，建立或恢复专用项目，并通过当前原生客户端的登录、模型与容量核验，不需要另配 API key。可选本地控制插件另行连接；本次不涉及插件市场或应用商店发布。

聊天会将消息、附件图片和必要项目记忆发送到模型服务，并消耗账号额度。检查点整理与做梦维护也会调用模型；自动做梦模式在空闲、额度及维护条件满足时可运行，想自行启动时可在维护页改为手动。预算为估算目标，不能保证绝对不超；聊天账本不保存正文，共享账号额度变化也不能精确归因到单个任务。额度显示本身不发送模型提示词。

保留既有项目目录和原始资料，不用新建项目代替可恢复的旧会话。同设备切换账号仍共用桌宠人物与项目。界面显示容量是上下文保护依据，与累计 token 账本不同；缓存输入和推理输出分别是输入、输出的子集，不重复相加。

## English

This release collects the changes since public v0.3.51. Windows x64 and macOS 13+ universal installers have completed build, checksum, native installation and startup verification.

### Changes

1. **Companion text/image chat and persistent memory**: send through the signed-in Codex account, receive streamed replies, interrupt generation and choose an available model. A dedicated project stores persona, preference and fact records. Checkpoints retain traceable source text, original images, summaries and revisions; offline search can revisit history, and handoff switches conversations after validation.
2. **Chat management and native usage**: seven pages cover current chat, usage, archive history, memory, handoff/maintenance, dream maintenance and project/models. A separate native token ledger, context growth, maintenance stages and budgets keep missing measurements unknown. Archive titles, tags, favorites and hidden state use independent metadata, preserving original JSONL and images.
3. **Clearer settings and writing**: five settings categories group general, appearance, bubbles/display, chat, and interaction/audio. Chat uses 14px message text and a 16px expandable writing card. The same input preserves drafts, selection, input-method composition and edits made during sending. Enter adds a line, Ctrl/Cmd+Enter sends, and Escape collapses the card; both languages and reduced motion are supported.
4. **Recovery and model discovery**: reconciliation reports progress and specific results. Compatible capacity proofs can survive program or CLI upgrades after integrity, original-thread terminal-state and current-capability checks. Writer conflicts, expired authentication, insufficient capacity and unknown execution remain distinct; the original thread and input are preserved without replaying unknown requests or silently starting another chat. Model refresh reads the verified native catalog, including Terra when actually available.
5. **Existing desktop features retained**: quota, observed account windows, reset forecasts, original characters and images, audio, page settings and local controls remain available. Windows follows with an independent top-level widget owned by the Codex main window; macOS retains its separate following window. Upgrades retain existing settings and imported characters.
6. **Reset forecasts and announcement reminders**: the reset forecast page reads bounded public announcement and observation data from `codex-reset.com`, showing source citations, announcement/observation deadlines, the real target countdown, 24/48-hour probabilities, confidence, last confirmation and freshness. Each locally observed account keeps its five-hour progress; an expired window produces widget text, four bounces in one second and one short sound, with deduplication and disable controls. Historical estimates are marked for login confirmation. Announcement, observation, Tibo self-report and real quota confirmation remain separate evidence layers; network failures, expiry or source changes keep bounded stale/offline cache data without blocking startup.

### Use and upgrade

Live quota requires the official Codex desktop app to be installed and signed in. Chat requires enabling its optional page, creating or resuming a dedicated project, and passing the current native client's login, model and capacity checks. No separate API key is required. The local control plugin uses a separate optional connection step; this release does not publish to a plugin marketplace or app store.

Chat sends messages, attached images and relevant project memory to the model service and consumes account quota. Checkpoint and dream maintenance also make model requests. Automatic dream mode can run when its idle, quota and maintenance conditions are met; choose manual mode in maintenance if you want to start it yourself. Budgets are estimates, not guaranteed charge limits. The usage ledger stores no message bodies, and shared account-quota changes cannot be precisely assigned to one task. Quota display alone sends no model prompts.

Keep the existing project directory and original records; do not create a replacement project for a recoverable conversation. Logins on one device share the companion identity and project. Context capacity is a sending safeguard, separate from cumulative token usage. Cached input and reasoning output are subsets of input and output and must not be added twice.
